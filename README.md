## ✨ 系統特色
1. **邀請卡主視覺背景 + 太平國小校徽 + 傳統五圓金章「捐款芳名錄」**
2. **單頁智慧滿版演算法**：所有捐款芳名錄全部呈現在同一頁（不捲動、不輪播隱藏），且每張紅紙大小完全一致、字體自動最大化，長輩觀看清晰不比較。
3. **每 5 秒自動更新 + 金光賀喜特效**：支援 Google Apps Script (GAS) 雲端試算表後台，每 5 秒自動同步最新資料。
4. **雙模式一鍵切換**：支援「📜 傳統紅紙直書風」與「🪪 現代喜慶橫式金卡」。
5. **禮金自動轉國字大寫**：後台輸入 `1000` 自動轉為 `禮金壹仟元整`，輸入物資名稱則自動保留。

詳細操作與 GAS 設定步驟請參閱 [`部署與使用說明.md`](./部署與使用說明.md)。
